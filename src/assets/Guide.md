# 📂 assets 폴더 가이드

`src/assets` 폴더는 프로젝트에서 사용하는 **정적 자산(Static Assets)**을 관리하는 공간입니다. 컴포넌트에서 직접 참조하거나 스타일 시트에서 연결하여 사용하는 파일들이 위치합니다.

## 1. 폴더 내부 구성

- **`/fonts`**: 서비스에서 사용하는 로컬 폰트 파일이 저장됩니다. 현재 `Pretendard` 폰트 패밀리가 구성되어 있습니다.
- **`/images`**: 배경 이미지, 로고, 일러스트 등 일반 이미지 파일을 관리합니다.
- **`/icon`**: 아이콘으로 사용될 SVG 원본 파일들이 위치합니다. (CSS Mask 방식 사용 시 `public/assets/icon`과 동기화 필수)

## 2. 폰트 관리

현재 `Pretendard` 자산이 추가되어 있으며, 모든 폰트는 반드시 `src/styles/font.css`에 등록 후 사용해야 합니다.

- **파일 위치**: `src/assets/fonts/pretendard/`
- **등록 방식**: `src/styles/font.css`에서 `@font-face`를 정의하여 프로젝트 전역 변수와 연결합니다.
- **참조 규칙**: 웹 최적화를 위해 `.woff2` 형식을 우선적으로 참조합니다.

## 3. 자산 관리 규칙

- **네이밍 컨벤션**: 모든 자산 파일명은 **소문자**와 **언더바(`_`)**를 사용하는 `snake_case`를 준수합니다.
  - 예: `arrow_left.svg`, `main_logo.png`
- **아이콘 최적화**:
  - SVG 아이콘은 내부 `fill` 속성을 제거하거나 `currentColor`로 설정하여 `src/styles/icon.css`에서 색상 제어가 가능하도록 합니다.

## 4. 활용 프로세스 (필수 준수)

모든 자산은 폴더에 추가하는 것에 그치지 않고, 반드시 **styles 설정 파일에 등록**하는 과정을 거쳐야 합니다.

1. **자산 추가**: 새로운 이미지/폰트/SVG를 `src/assets` 내 알맞은 하위 폴더에 추가합니다.
2. **아이콘 동기화**: 아이콘의 경우 `public/assets/icon` 폴더에도 복사본을 저장하여 CSS Mask 경로(`url('/assets/icon/...')`)를 확보합니다.
3. **스타일 등록 (중요)**:
   - **아이콘**: `src/styles/icon.css`에 클래스를 등록합니다.
   - **폰트**: `src/styles/font.css`에 `@font-face`를 등록합니다.
4. **사용**: 등록된 클래스명이나 폰트 패밀리명을 사용하여 컴포넌트에 적용합니다.
